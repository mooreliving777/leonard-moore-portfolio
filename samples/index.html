Problem and design decisions

  1. Convert strict USD input strings into integer cents without floating-point multiplication.
  2. Reject invalid input, negative amounts, unexpected decimal precision and unsafe large values.
  3. Demonstrate simple retry protection in memory while acknowledging that durable database and concurrency guarantees require additional safeguards.
